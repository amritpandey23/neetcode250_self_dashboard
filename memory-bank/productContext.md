# Product Context

## Why
Grinding NeetCode 250 without a personal tracker makes it easy to lose notes and forget what was already solved vs still shaky.

## How it should work
1. User registers / logs in
2. Sees all 250 problems with category, difficulty, and links
3. Updates status inline or on a detail page
4. Writes notes (approach, complexity, mistakes)
5. Filters the list and reads overall completion %

## UX goals
- Fast to update status from the list
- Notes easy to edit on a dedicated problem page
- Clear progress without clutter
