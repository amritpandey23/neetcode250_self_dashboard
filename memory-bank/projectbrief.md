# Project Brief

## Goal
A personal self-dashboard for tracking NeetCode 250 interview prep: progress status and notes per problem.

## Scope
- Flask + SQLite web app
- Auth: register, login, logout
- Seed all 250 problems from `neetcode_250_complete.json`
- Track status and notes per user/problem
- Dashboard filters and progress overview
- One shared question of the day on the dashboard; email it only to users who opt in

## Out of scope (for now)
- Multi-user collaboration
- Cloud sync / hosted auth providers
- Spaced-repetition scheduling
